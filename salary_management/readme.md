# Employee Salary Management System

## About the Project

The Employee Salary Management System is a web application developed using Python, Django, and MySQL.

It helps manage employee details, departments, and salary records in one place.

## Technologies Used

- Python
- Django
- MySQL
- HTML
- CSS
- Bootstrap
- JavaScript

## Features

- Employee Management
- Department Management
- Salary Management
- Add Employee Details
- Edit Employee Details
- Delete Employee Details
- View Employee Records
- Manage Salary Records
